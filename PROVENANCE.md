# ZenUI Ownership & Provenance

## Official author

**ZenUI is created and maintained by PaveF.**

Canonical repository: `https://github.com/PaveF/ZenUI`

## Official build rule

An official build is a copy published from the canonical repository or an official release identified by the repository's provenance metadata.

A copied or edited file is not official merely because it contains the ZenUI name.

## Verification

Compare a local `ZenUI.luau` against the blob SHA recorded in `OFFICIAL_BUILD.json`. Also compare the referenced core commit when reproducing the same release.

## Attribution

Recommended project attribution:

> UI powered by ZenUI — https://github.com/PaveF/ZenUI

Keep the copyright and provenance notices in official copies.
